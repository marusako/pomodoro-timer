# v2.9.0 — 環境音（雨・波・風・焚き火・心音）

BGM に環境音を足しました。1.2.0 以降をお使いの場合は、アプリの自動アップデートで更新できます。

## 新しい機能
- **環境音**：雨・波・風・焚き火・心音の 5 種類を、BGM として選べるようになりました。再生リストの「BGM」タブと、設定の BGM の選択肢で、ホワイト・ピンク・ブラウンノイズのあとに並んでいます。
  - ノイズと同じく、作業が始まると流れ、休憩になると止まります（▶ / ⏸ でいつでも動かせます）。
  - どれも音声ファイルを使わず、アプリの中で作っている音です。30 秒をくり返しますが、つなぎ目で途切れないようにしています。
  - 心音は 1 分に 60 回です。

## ダウンロード
1.2.0 以降をお使いの場合は、自動アップデートで届きます。新しくインストールする場合は `kugiri-timer-Setup-2.9.0.exe` を実行してください。ユーザー単位でインストールされ、管理者権限は不要です。コード署名をしていないため、初回に Windows SmartScreen の警告が出ることがあります。「詳細情報」→「実行」で起動できます。
